# PesaTrack KE

PesaTrack KE is a simple mobile expense tracker built with React Native (Expo) for Kenyan users.

## Features
- Add income / expense in Ksh
- Balance summary
- Transaction history
- Local storage with AsyncStorage

## Tech Stack
- React Native / Expo
- AsyncStorage

## How to Run

    git clone https://github.com/wycliffe36/pesatrack-ke
    cd pesatrack-ke
    npm install
    npx expo start
